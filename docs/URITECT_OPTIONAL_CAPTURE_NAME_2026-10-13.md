# Photo review and optional name — source 1.5.20+38

Captured/imported selected-photo previews fill the border using a centered cover fit. This crops displayed edges without stretching or modifying the source image used for analysis.

Review Photo retains the reading-time selector, explicit current-specimen confirmation and relevant duplicate/context notices. The optional specimen-code entry and its technical drawer are replaced by Input Name (optional). Names are trimmed, limited to 100 characters, saved with the encrypted record, and remain editable through authenticated history. Later name edits, including clearing a name, take precedence over the original capture name when checklist updates merge.

The legacy specimenCode field remains readable for existing records. It is no longer a required condition for current-context interpretation because the entry has been removed; an arbitrary self-reported code never independently authenticated specimen identity. The name is optional and never substitutes for identity, timing or confirmation. Source/hash integrity, duplicate checks, photo age, current-specimen confirmation and reported timing remain required by the context gate. Image quality, direction, model-support, per-analyte confidence and clinical eligibility gates are unchanged. Specimen identity and reaction timing remain self-reported workflow limitations.

These source changes are not evidence of an installed APK or validated model improvement.
